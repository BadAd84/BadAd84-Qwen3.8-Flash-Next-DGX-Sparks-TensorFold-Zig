## Environment notes for whoever continues

- The no-copying rule and the single-lever rule are in `PROMOTION-RULES.md` (this repo, GLM Zig,
  DeepSeek TP2, Inkling) and GLM Python's `AGENTS.md`; fleet text in `~/.omp/agent/RULES.md` section 8.
- `ds41-direct` is OUT (402 balance); use `ds41-nozdr`; `glm-5.4` and `kimi-k3.1-pro` are approved
  cross-check engines.
- The multi-line remote write trap: heredocs through ssh to spark6 produced empty files repeatedly;
  `printf` to a local file then `scp` works. `git -C <relative>` resolves against the cwd; anchor the
  repo root in a variable.
- `git apply` inside an enclosing repo silently changes nothing: init the staging tree first, or use
  absolute patch paths.
- The committed-patch trap: a patch can be committed while `git apply` rejects it, and every tree
  called "the applied head" silently lacks it. Prove the whole series applies from a fresh extract
  after any patch edit (the skill `prove-a-numbered-patch-applies-before-committing-it`).
- SHA256SUMS files must be LF: the package gate's dollar-anchored grep cannot match through a CR;
  `.gitattributes` now pins `SHA256SUMS text eol=lf`.
- The image build's two-base conflict and the working sibling-build pattern (recipe dir with one no-op
  patch, TF_REF pinned in the sourced config) are recorded in
  `docs/receipts/PrefillKsArm/BUILD-FAILURE.md`.
